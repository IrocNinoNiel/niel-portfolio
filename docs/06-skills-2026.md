# Finding 06 - Update Skills Section for 2026 Relevance

## Finding

Recruiters keyword-scan skills sections. In 2026, full stack developer job descriptions
routinely include CI/CD, cloud platforms, containerization, and AI/LLM tooling as expected
skills alongside the core framework stack. A skills section that lists only frontend
frameworks, backend frameworks, and databases reads as incomplete against the current
job market.

> "Modern full stack developers are expected to own the entire application lifecycle,
> from conception through deployment and maintenance, whilst working with multiple
> technologies including containerisation, serverless computing, and real-time data processing."
> - talent500.com

## Why It Matters for This Portfolio

The current Skills section has three categories: Frontend, Backend, and Tools & Databases.
Docker is listed but CI/CD is absent. Cloud platforms are absent. AI tooling is absent.
TypeScript is listed under Frontend but is more accurately a cross-cutting skill.
The section does not reflect the full scope of a 2026 full stack developer role.

---

## Action Plan

### Step 1 - Add Missing Skills You Already Have

Add skills that reflect work already done at Syntactics, not aspirational skills:
- **CI/CD:** GitHub Actions (if used), or note deployment pipeline experience
- **Cloud/Hosting:** Vercel, Railway, or any cloud service used in production
- **API tooling:** Postman, Swagger/OpenAPI (if used for API documentation)
- **Version control:** Git is listed, add if applicable: GitLab, Bitbucket

Only add skills you can speak to in an interview.

### Step 2 - Restructure the Categories

**Current:**
- Frontend
- Backend
- Tools & Databases

**Proposed:**
- Frontend
- Backend
- Databases
- DevOps & Deployment
- (AI & Integrations - add when the AI project is built, see Finding 01)

### Step 3 - Reorder by Recruiter Priority

Move Docker up in visibility - it is more valued in 2026 than it appears buried in
"Tools & Databases". Lead the DevOps category with it.
